# Deep space command console

A single-file, no-backend mission-control simulator for sending commands to Voyager 1, Voyager 2, New Horizons and Juno, with real light-time delay, a command queue and a time-warp slider.

Open `index.html` in a browser, or host it on GitHub Pages (Settings -> Pages -> Deploy from branch -> main / root).

Add probes or commands in the DATA section at the top of the script in `index.html`.
